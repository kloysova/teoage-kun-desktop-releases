# てをあげくん for Desktop 配布物

てをあげくん for Desktop（Windows 版・Mac 版）のインストーラーを置くリポジトリです。ソースコードはありません。

ダウンロードと入れ方は、施設の管理者から案内された配布サイトをご覧ください。はじめて開くときに OS が警告を出すことがあり、サイトに開き方（押すところの図つき）を載せています。各版のファイルは、この Releases に置いています。

## Release のタグ

| タグ | 内容 |
|---|---|
| `windows-v<版>` | Windows 版（x64・ARM64）のインストーラー。自動更新の確認に使う目録も置く |
| `mac-v<版>` | Mac 版（macOS 14 以降）の .dmg と .zip |
| `desktop-v<版>` | Mac 版（macOS 11〜13 向け）の .dmg と .zip |

## ご注意

- Release を削除・非公開にしないでください。Windows 版は、自動更新の確認にこのリポジトリの Releases を読みます。
- ファイルが正しいかは、配布サイトの更新履歴にある SHA-256 で確かめられます。
- 「試験版」（プレリリース）は、施設に配る版ではありません。
